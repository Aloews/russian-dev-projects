# Agent operating instructions

Before changing this repository, read the portable [Reality-First Autonomous Engineering skill](.agents/skills/reality-first-autonomous-engineering/SKILL.md) and its security/cost reference.

This repository is a public directory of independent Russian developer projects. Preserve contributor content, project descriptions, status tables, attribution, links, and contribution rules. Do not apply product-development assumptions to third-party projects or modify listed projects without an explicit scoped request.

The skill defines the execution process; it does not grant permissions, override repository contribution rules, or authorize paid resources, destructive changes, or releases. For every substantial repository change, define observable acceptance criteria, inspect the baseline, work on an isolated branch, validate links/formatting/content as applicable, inspect the complete diff, and report only evidence-backed outcomes.

Do not send routine progress narration. Escalate only a material decision, genuine blocker, security/cost risk, or final evidence-based handoff.
