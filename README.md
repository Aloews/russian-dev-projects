## ❓ Зачем нужен этот репозиторий?

Как разработчику, интересно узнать, над чем работают другие люди в своих хобби-проектах (независимо от цели: зарабатывание денег, хобби или просто попробовать).

Поэтому мы создали этот репозиторий. Добро пожаловать, добавляйте свои проекты! Отправляйте Pull Request или создавайте Issue.

**Критерии отбора**: проект должен быть веб-сайтом или мобильным приложением (не инструменты для разработчиков или форумы)

### 📝 Правила написания описания продукта

**Важно**: ❌ `AI-инструмент для видео` → ✅ `Генерируйте вертикальные видео за 3 шага без навыков монтажа`

👉 [Как написать хорошее одностроковое описание продукта](./CONTRIBUTING.md)
