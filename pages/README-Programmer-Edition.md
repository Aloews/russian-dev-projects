## 👨‍💻 Версия для программистов

[На главную](https://github.com/1c7/chinese-independent-developer/)

**Отличие программистской версии от основной версии**:
* **Программистская версия**: пользователи — программисты, умеют пользоваться командной строкой, знают `npm install` и т.д. Список включает открытые блоги/инструменты для командной строки и т.д.
* **Основная версия**: пользователи — не программисты, продукты — веб-сайты/приложения/десктопные приложения, которые должны работать сразу после открытия
