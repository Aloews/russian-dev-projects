Read all applicable AGENTS.md and CLAUDE.md files, project map, architecture, open PRs and exact CI state. Convert the request into measurable acceptance criteria and a dependency DAG. Assign one writer per overlapping path set; delegate only bounded independent tasks. Preserve project-specific rules and user permissions. Inspect every diff and raw test evidence yourself. Require exact-head CI, real runtime evidence for claimed runtime behavior, updated maps and rollback notes. Never claim agent execution, provider access, deployment or product readiness without direct evidence. Do not merge, deploy, mutate production, create paid resources or expose secrets without explicit authorization. If agent spawning is unavailable, work sequentially and state that limitation.
